## Featured — Mirrors

Roblox tooling construído em torno de UI customizada, automação e infraestrutura web.

Mirrors combina sistemas client-side em Luau com infraestrutura externa quando um projeto precisa de mais do que o Roblox oferece sozinho.

**Stack atual:**

| Camada | Tecnologia |
|---|---|
| Scripting Roblox | Luau |
| UI / Interfaces | WindUI |
| Backend / Automação | JavaScript, Node.js |
| Web / APIs | Next.js |
| Banco de dados / Auth | Supabase |
| Deploy | Vercel |
| Integrações | Discord.js |

## Web & Backend

Também construo a infraestrutura por trás dos meus projetos.

```
Frontend
   ↓
Next.js / HTML / CSS / JavaScript
   ↓
API
   ↓
Vercel / Node.js
   ↓
Supabase
   ↓
Database / Auth / Logs
```

Uso essa arquitetura para autenticação, configuração, logging, key systems, APIs e dashboards de projetos.
